# D001 — 目标内核版本定为 ACK `android12-5.10`（Linux 5.10 LTS，GKI 2.0）

- **状态**：已定（用户拍板 5.10，具体 ACK 分支由本记录确定，允许 S1 后复核）
- **日期**：2026-10-17
- **决策者**：用户（"先试试 5.10"）+ PI-Desktop 对分支选择提案

## 背景

cepheus 原厂内核为 4.14（非 GKI）。项目目标是让它在**未来若干年**仍能跟进安全补丁与新 Android 用户空间。可选的 GKI 基线：

| 基线 | AOSP 分支（已验证存在） | 上游 LTS EOL（Google `kernel-lifetimes`） |
|---|---|---|
| 5.4 | `android11-5.4` / `android12-5.4`（标 `non-GKI`，无 release） | 2026-01（已过期） |
| **5.10** | `android12-5.10` / `android13-5.10` | **2027-07** |
| 5.15 | `android13-5.15` / `android14-5.15` | 2028-07 |
| 6.1 | `android14-6.1` | 2029-07 |
| 6.6 | `android15-6.6` | 2028-07 |
| 6.12 | `android16-6.12` | — |
| 6.18 | `android17-6.18`（= Android 17 的 GKI 基线，实测 `6.18.0-rc6`） | — |

硬约束不是内核性能，而是**闭源 HAL 与内核 ABI 的耦合**：display 的 `msm_drm`/ION 与 gralloc、camera 的 CAMX 与 `cam_sync`/ioctl、audio 的 `mixer_paths.xml` 与 techpack kcontrol 名、wifi 的 qcacld 版本、power/thermal 的 `msm_performance`/kgsl 节点——这些都是**我们无法修改的二进制**，内核越新，咬合成本越高。

## 决策

1. **目标内核 = Linux 5.10，走 GKI 2.0 形态**（GKI `Image` + vendor 模块 `.ko`）。
2. **主基线分支 = `android12-5.10`**；`android13-5.10` 作为同 LTS 线的可选替换，S1 实测后可无损切换（配置差异可控）。
3. **明确不把 6.x 作为本项目第一阶段目标**；`android17-6.18` 的存在只用于确认"Android 17 的官方 GKI 基线是 6.18"，不作为移植目标。

## 理由

**已验证事实**
- `android17-6.18` 分支存在且为 6.18.0-rc6 → Android 17 官方基线是 6.18。
- 5.10 的 LTS EOL 为 2027-07；5.4 已于 2026-01 EOL，因此**"5.4 已经过期，5.10 是仍然受维护的最小可用 GKI"**。

**判断（未验证，需 S1 实测）**
- 5.10 是从 4.14 世代 vendor blobs 出发**仍可能闭环**的最后一代；6.x 会强制相机/显示栈重写。
- 已有 5.4 前移树可直接复用其 SM8150 DTS 与驱动前移经验，5.4 → 5.10 的增量（同 CAF msm-5.x 代码组织：`techpack/*`）远小于 4.14 → 5.10 全量前移。

## 备选方案与否决理由

- **6.1 / 6.12 / 6.18**：寿命最长（6.1 到 2029），但需要把 techpack display/camera/audio 正向移植跨多个 API 大改，且旧 CAMX/gralloc 基本不可能咬合。**否决为第一阶段目标**，留作 S3 可选。
- **5.15**：跨过 5.10 直接到 5.15 并无明显收益（EOL 只差 1 年，CAF msm-5.15 techpack 与 5.10 差异更大），**否决**。
- **留在 4.14**：官方已标非 GKI、上游 2024-01 EOL，只能吃社区 backport。**否决为长期方案**，但保留为出货主线（见 Q003）。

## 影响与后续

- 源码来源、模块策略、启动链形态随之确定 → 见 D002、D003。
- **复核触发条件**：若 S2 阶段发现 5.10 与 cepheus blobs 存在无法绕过的 ABI 断裂（尤其 ION 与相机），则重新评估"5.10 单体自洽（非 GKI）"或"降回 5.4 但延长维护"。
