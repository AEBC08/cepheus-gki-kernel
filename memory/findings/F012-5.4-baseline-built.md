## 2. 与作者配方的差异（已记录）

CI 在 `arch/arm64/configs/vendor/xiaomi/cepheus.config` 末尾追加了：

```
# 由 CI 追加：关闭 full LTO 以缩短基线构建时间（不属于作者原配方）
# CONFIG_LTO_CLANG is not set
# CONFIG_LTO is not set
```

原因：full LTO 在 4 vCPU runner 上极易超时/被杀（我们在 ACK 5.10 上踩过，F005）。
需要严格对照作者配方时可传 `lto=1` 重新构建。
